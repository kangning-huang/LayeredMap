Mac 用・無料

ネットで地図データを見つけたら、NimbleMap にドラッグ。

Shapefile、GeoPackage、NetCDF、GeoTIFF、GPX、KML、座標付きの CSV。NASA や USGS（米国地質調査所）、自治体のオープンデータポータルからダウンロードするファイルです。NimbleMap なら数秒で地図として開けます。GIS の知識も設定も要りません。

ファイルを NimbleMap にドラッグするだけ。Shapefile、GeoPackage、NetCDF はダブルクリックでもすぐに開けます。

Mac 版を無料でダウンロード データはどこで手に入る？

NimbleMap には Apple シリコン搭載の Mac が必要です。Windows 版も準備中です。

開けるファイル

実際にダウンロードするファイルを、そのまま

ファイルを NimbleMap にドラッグすれば、正しい投影法で正しい位置に表示され、すぐに探検できます。

  • .shp

    Shapefile

    境界、道路、嵐の経路。.dbf、.shx、.prj ファイルを同じ場所に置いておいてください。

  • .zip

    zip に入った Shapefile

    解凍せずに、そのまま開けます。

  • .gpkg

    GeoPackage

    たくさんのレイヤーをまとめて入れられる、すっきりした 1 つのファイル。

  • .geojson.json

    GeoJSON

    Web の地図形式。オープンデータポータルや API でよく使われます。

  • .csv.tsv.xlsx

    表

    緯度と経度の列がある CSV、TSV、Excel。

  • .kml.kmz

    KML と KMZ

    Google Earth の目印、パス、ポリゴン。

  • .gpx

    GPX

    腕時計やスマートフォンで記録したランニング、サイクリング、ハイキング。

  • .tif.tiff

    GeoTIFF

    標高、土地被覆、衛星画像、ドローン画像。

  • .nc

    NetCDF

    気候や気象のグリッド。タイムスライダーで再生できます。

Shapefile、GeoPackage、NetCDF はダブルクリックで NimbleMap が開きます。ほかのファイルはダブルクリックすると別のアプリで開くので、NimbleMap にドラッグするか、右クリック › このアプリケーションで開く › NimbleMap を選んでください。

開いたら

あとは探検するだけ

ズームと移動

スクロール、ピンチ、ドラッグで、地球全体から 1 本の海岸線まで。

地名もデータも検索

都市名を入力すればそこへ飛び、名前を入力すればファイルの中から見つけ出します。この例では、Haiyan という名前の嵐をすべて。

何でもクリック

それが何で、ほかと比べてどうかがわかります。2011年の東北地方太平洋沖地震は、14,537 件の 99% より強い地震でした。

時間を再生

時間ステップのあるファイルにはスライダーが付きます。再生ボタンを押して、ひと夏の熱波が動いていく様子を見てみましょう。

どの数字も、画面に見えている部分だけでなくデータ全体から計算されます。どの操作も取り消せます。
