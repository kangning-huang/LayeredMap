도움말

도구 상자가 아니라 이야기로 시작하세요

아래의 작업 예제는 모두 앱에 들어 있는 예제를 사용하므로 지금 바로 따라 해 볼 수 있습니다. 모든 단계에서 버튼 이름은 앱에 표시된 그대로 적었습니다.

태풍: 가장 강력했던 폭풍

폭풍 경로 4,999개를 열고, 하이옌을 찾아 순위를 확인한 다음, 5등급 폭풍만 남깁니다.

무료 · 10분 · 클릭, 색칠, 필터

2023년 폭염의 시간에 따른 변화

여름 한 철의 일별 기후 데이터를 시간 슬라이더로 재생하고, 셀 하나하나의 값을 읽고, 완성된 지도 이미지를 내보냅니다.

무료 · 10분 · 시간 슬라이더, 내보내기

1866년 중국의 성곽 도시

성벽을 위성 영상 위에 올리고, 크기순으로 순위를 매기고, 성도(省都)만 걸러 낸 뒤 결과를 공유합니다.

무료 · 15분 · 위성, 비교, 공유

1분 만에 보는 NimbleMap 창

  • 도구 모음(위쪽): 검색 상자 Search places or your data(장소 또는 내 데이터 검색), 이어서 Open(열기, ⌘O), Layers(레이어, ⌘L), Undo(실행 취소, ⌘Z), Share(공유, ⌘E).
  • 레이어 패널(왼쪽): 지금까지 연 모든 것이 여기에 있습니다. 눈 아이콘으로 레이어를 보이거나 숨기고, 끌어서 순서를 바꾸고, 오른쪽 클릭으로 더 많은 메뉴를 엽니다.
  • 카드(오른쪽): 무언가를 클릭하면 나타납니다. 그 대상의 정보, 나머지 가운데 어디쯤에 있는지, 그리고 추천 버튼을 최대 세 개까지 보여 줍니다. 레이어 카드에는 Overview(개요), Style(스타일), Details(세부 정보) 탭이 있습니다.
  • 지도 컨트롤(오른쪽 아래): Zoom in(확대), Zoom out(축소), 배경 지도 버튼. 축척 막대는 왼쪽 아래에 있습니다.
  • 모든 것을 되돌리기: 색 하나 바꾸기부터 필터, 레이어 제거까지 모든 변경은 실행 취소 한 번으로 되돌릴 수 있습니다. 원본 파일은 절대 바뀌지 않습니다.

내 파일 열기

파일을 NimbleMap으로 끌어다 놓거나 Open(열기)을 사용하세요. NimbleMap은 CSV와 Excel(위도·경도 열이 있는 것), GeoJSON, Shapefile, GeoPackage, KML/KMZ, GPX, GeoTIFF, NetCDF를 읽습니다. 어떤 열이 좌표인지처럼 앱이 무언가를 가정해야 했다면, 카드에 한 줄로 알려 주고 옆에 Change(변경)를 둡니다. Amap(가오더), Tencent, Baidu 지도에서 복사한 점은 GPS 좌표로 옮길 수 있습니다. GCJ-02를 참고하세요.

모르는 용어가 있나요?

용어집에서 지도 용어를 쉬운 말로 풀이하고, 각 용어가 앱의 어디에 나오는지 알려 줍니다.

NimbleMap 업데이트

NimbleMap은 열릴 때와 NimbleMap › 업데이트 확인…을 선택할 때 새 버전이 있는지 확인합니다. 새 버전이 있으면 지도 오른쪽 아래에 작은 알림이 나타납니다. 지금 업데이트를 클릭하면 NimbleMap이 새 버전을 다운로드하고, 디지털 서명과 체크섬을 확인한 다음, 스스로를 교체하고 다시 열립니다. 저장하지 않은 변경 사항이 있으면 먼저 묻습니다. 웹사이트를 다시 방문할 필요가 없습니다.

지도도 앱과 함께 업데이트됩니다. 예제 지도와 내장된 세계 레이어는 NimbleMap 안에 들어 있으므로 앱과 함께 업데이트됩니다. 온라인 배경 지도는 항상 최신 상태입니다.

디스크 이미지에서 바로 실행 중이거나 계정이 응용 프로그램 폴더를 변경할 수 없는 경우처럼 NimbleMap이 스스로를 교체할 수 없으면, Finder에서 새 버전을 엽니다. NimbleMap을 응용 프로그램 폴더로 드래그하세요. 0.7.1 이하 버전에는 ‘지금 업데이트’가 없습니다. 다운로드 페이지에서 새 버전을 한 번 다운로드하세요.

개인정보. 확인할 때는 nimblemap.com(또는 GitCode의 사본)에서 작은 파일 하나만 읽으며, 사용자에 관한 정보는 아무것도 보내지 않습니다. 식별자 없이 앱의 버전 번호만 보냅니다. 보기 › 오프라인으로 작업이 켜져 있으면 확인하지 않습니다.

피드백 보내기: 앱의 도움말 › 피드백 보내기… 또는 GitHub Discussions.

개인정보

앱에서 보내는 피드백. 도움말 › 피드백 보내기…를 선택하면 NimbleMap은 작성한 내용을 피드백 서비스로 보내고, 이 서비스는 그것을 GitHub Discussions(github.com/kangning-huang/NimbleMap/discussions)에 공개로 게시합니다. 누구나 읽고 답글을 달 수 있습니다. 게시물에는 메시지, 제목(입력한 경우), 피드백 종류, 인터페이스 언어가 들어갑니다. 앱과 macOS 버전 번호는 앱 버전과 macOS 버전 포함을 체크한 채로 두었을 때만 들어갑니다. 이메일 주소, 이름, 계정, 지도, 파일은 절대 들어가지 않습니다. GitHub 계정은 필요 없습니다.

이메일 주소를 입력하면, 답장을 보내기 위한 용도로만 게시물 링크와 함께 서버에 비공개로 저장됩니다. 공개적으로 표시되지 않습니다. 대화가 끝나면 삭제하며, 길어도 1년 안에 삭제합니다. 더 일찍 삭제를 원하면 연락해 주세요.

로그인한 상태라면 게시물에는 로그인한 사용자가 보냈다는 사실만 표시되고, 서버는 후속 연락을 위해 계정 ID를 게시물 링크와 함께 비공개로 저장합니다. 공개적으로 표시되지 않으며, 대화가 끝나면 삭제하고 길어도 1년 안에 삭제합니다.

스팸을 막기 위해 앱은 컴퓨터에서 만든 임의의 설치 번호를 보내고, 서버는 네트워크 주소를 봅니다. 둘 다 집계용으로 키를 사용한 단방향 해시로만 저장하며, 일주일 뒤 삭제합니다.
