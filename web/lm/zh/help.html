帮助

从一个故事开始，而不是一堆工具

下面每个教程用的都是应用自带的示例数据，现在就可以跟着做。步骤里提到的按钮，名称都和应用里一模一样。

凌波微图（NimbleMap）的界面目前是英文的（中文界面正在制作中）。为了让你在屏幕上一眼找到，文中的按钮名称保留英文原文，第一次出现时在括号里注明中文意思。

台风：哪些风暴最猛烈

打开 4999 条台风路径，找到 “海燕”，看看它排第几，再只留下五级超强台风。

免费版 · 约 10 分钟 · 点选、上色、筛选

2023 年热浪：随时间变化

用时间滑块播放一整个夏天的逐日气候数据，查看单个格子的数值，最后导出一张完整的地图图片。

免费版 · 约 10 分钟 · 时间滑块、导出

1866 年的中国城墙

把城墙轮廓叠到卫星图上，按面积排出名次，筛出各省省城，再把结果分享出去。

免费版 · 约 15 分钟 · 卫星图、比较、分享

一分钟认识窗口

  • 工具栏（顶部）：搜索框 Search places or your data（搜索地名或你的数据），右边依次是 Open（打开，⌘O）、Layers（图层，⌘L）、Undo（撤销，⌘Z）和 Share（分享，⌘E）。
  • 图层面板（左侧）：列出你打开的所有内容。眼睛图标用来显示或隐藏图层；拖动可以调整顺序；右键还有更多选项。
  • 卡片（右侧）：点击地图上的东西就会出现。它列出各项信息、这个东西在同类里处于什么位置，以及最多三个推荐操作按钮。图层卡片有 Overview（概览）、Style（样式）、Details（详情）三个标签页。
  • 地图控件（右下角）：Zoom in / Zoom out（放大/缩小）和底图按钮。比例尺在左下角。
  • 什么都能撤销：改颜色、加筛选、移除图层……每一次改动都是一步撤销。你的原始文件永远不会被修改。

打开你自己的文件

把文件直接拖进凌波微图，或者点 Open。凌波微图能读 CSV 和 Excel（需带经纬度列）、GeoJSON、Shapefile、GeoPackage、KML/KMZ、GPX、GeoTIFF 和 NetCDF。如果应用不得不做些推断，比如哪几列是坐标，卡片上会用一行字说明，旁边有 Change（更改）。从高德、腾讯或百度地图里复制出来的点，可以一键换算到 GPS 坐标，详见术语表里的 GCJ-02。

遇到不认识的词？

术语表用大白话解释地图术语，并告诉你它们出现在应用的哪个位置。

更新凌波微图

凌波微图会在启动时检查是否有新版本，你也可以选择 凌波微图 › 检查更新… 随时检查。有新版本时，地图右下角会出现一条小提示。点 立即更新：凌波微图会下载新版本，核对它的数字签名和校验和，替换自身后重新打开。如果有未保存的更改，会先询问你。不用再去网站下载。

地图随应用一起更新。示例地图和内置的世界图层都装在凌波微图里，会随应用一起更新。在线底图始终是最新的。

如果凌波微图无法替换自身（比如直接从磁盘映像里运行，或者你的账户不能修改“应用程序”文件夹），它会在“访达”中打开新版本：把凌波微图拖到“应用程序”即可。0.7.1 及更早的版本没有“立即更新”：请从下载页下载一次新版本。

隐私。检查更新只会从 nimblemap.com（或它在 GitCode 上的副本）读取一个小文件，不发送任何关于你的信息：没有任何标识符，只有应用的版本号。打开 视图 › 离线工作 后，凌波微图不会检查更新。

反馈

发送反馈：在应用里选择 帮助 › 发送反馈…，或前往 GitHub Discussions。

隐私

从应用发送的反馈。当你选择 帮助 › 发送反馈… 时，凌波微图会把你写的内容发送到我们的反馈服务，由它公开发布在 GitHub Discussions（github.com/kangning-huang/NimbleMap/discussions）上，任何人都可以阅读和回复。帖子包含你的留言、你填写的标题（如有）、反馈类型和界面语言。只有在你保留勾选 附带应用版本和 macOS 版本 时，才会附上应用和 macOS 的版本号。帖子绝不会包含你的电子邮件地址、姓名、账号、地图或文件。你不需要 GitHub 账号。

如果你留下电子邮件地址，它会私下保存在我们的服务器上，与你帖子的链接放在一起，只用于回复你，绝不会公开显示。对话结束后我们会删除它，最长保留一年；如需提前删除，请写信告诉我们。

如果你已登录，帖子只会注明“来自已登录用户”，我们的服务器会把你的账号 ID 私下保存在你帖子的链接旁边，以便跟进。它绝不会公开显示；对话结束后我们会删除它，最长保留一年。

为防止垃圾信息，应用会发送一个在你电脑上随机生成的安装编号，我们的服务器也会看到你的网络地址。两者都只以单向加密散列（带密钥）的形式保存，仅用于计数，一周后删除。
