术语表

地图术语，说人话

凌波微图（NimbleMap）的按钮尽量用日常用语，但地图数据自有一套行话。这里逐一解释每个词是什么意思、在应用里的什么地方会碰到。中英文都能搜。

比例尺与缩放级别 Scale and zoom level #

屏幕上能装下多大一块地球。缩放级别 0 用一张瓦片显示整个世界，每放大一级，细节翻一倍。比例尺告诉你屏幕上的一段长度对应地面上多远。

在应用里地图左下角是比例尺；右下角是 Zoom in / Zoom out（放大/缩小，⌘+ 和 ⌘−）。在 View 菜单里可选 Metric Units（公制）或 Imperial Units（英制）。
又称zoom · scale bar · resolution · 缩放 · 比例
变量 Variable #

格网文件里的一种测量量，比如 2 米气温、热浪强度，并带有单位。一个 NetCDF 文件里可以有很多个变量，地图一次显示一个。

在应用里图层名下方的 Variable shown 弹出菜单，例如 “2 m temperature (°C)”。
在教程中查看2023 年热浪：随时间变化 →
又称band · parameter · measure · 波段 · 要素变量
步骤说明（配方） Recipe #

用大白话记录一个结果是怎么得出来的：用了哪些图层、做了哪一步、范围是什么、排除了什么。可以复制成文字，方便核对。

在应用里每个分析结果，无论来自卡片上的按钮还是凌波微图 Pro 的提问框，都带一张结果卡片，列出各个步骤，并在地图上预览，你可以选 Keep（保留）或 Discard（放弃）。
在教程中查看台风：哪些风暴最猛烈 →
又称result card · method · provenance · how it was made · 方法
裁剪 Clip #

只保留图层落在某个区域里的那部分，就像沿着边界用剪刀剪地图。原文件不会被改动，结果是一个新图层。

在应用里卡片上的 Keep the part of [layer] inside [other] 按钮，所有人都能免费使用；结果的步骤说明里也这样写这一步。在凌波微图 Pro 里，还可以直接提问，例如 “只保留我画的区域里面那一段台风路径”。
又称cut · keep inside · crop · intersect · 相交
测地线（大地线） Geodesic #

沿着弯曲的地球表面来量，就像飞机真正飞的航线，而不是在平面地图上拉一条直线。在平面地图上，上海飞纽约的最短航线看起来是弯的；按测地线算，它才是 “直” 的。凌波微图计算距离和面积都用这种方法，所以 100 公里的圆，在赤道附近和在两极附近都是真正的 100 公里。

在应用里应用里显示的所有距离和面积都按这种方式计算：比例尺、“area · 23.4 km²” 这样的面积信息，以及分析里 “100 公里以内” 这类距离。
又称great circle · true distance · ellipsoid · 大圆 · 球面距离
导出地图图片 Map image (export) #

把地图做成一张完整的图片，带标题、图例、比例尺和数据来源，按实际尺寸绘制，可用于幻灯片、报告或社交媒体。

在应用里工具栏 Share › Map image…（⌘E）。尺寸可选 Slide 16:9（幻灯片）、Report A4（A4 报告）、Square（方形）；选项有 Title（标题）、Caption（说明）、Legend（图例）、Scale bar（比例尺）、North arrow（指北针）、Lat/lon labels（经纬度标注）。
在教程中查看2023 年热浪：随时间变化 →
又称export · share · PNG · save image · print
底图 Basemap #

垫在你的数据下面的背景地图，可以是街道、海岸线和地名，也可以是卫星影像。它的作用是帮你认路，不算你的图层，也不属于你的数据。

在应用里地图右下角的 Basemap（底图）按钮：Auto（跟随浅色/深色模式）、Light（浅色）、Dark（深色）、Satellite（卫星图，NASA “蓝色弹珠” 影像），以及 Offline（不用联网的轮廓图）。Background strength 可以把底图调淡，让数据更醒目。
在教程中查看1866 年的中国城墙 →
又称background · base map · satellite · tiles · 卫星图
对比信息 Insight line #

选中某个东西时，应用自动写出的一句话，告诉你它在同类里处于什么位置，比如 “highest of 4,999”（4999 个里最高）或 “lower than 80% of …”（比 80% 的……低）。它出现在任何工具之前，点一下就能有所发现。

在应用里点击要素或栅格格子后，卡片的最上方。Compare with other …（与其他……比较）会把它画成排名图。
在教程中查看台风：哪些风暴最猛烈 →
又称rank · compare · median · where it stands · 排名
范围（外包框） Extent #

刚好把一个图层全部数据框住的矩形，从最西到最东、从最南到最北。

在应用里Details › Extent；Zoom to layer（缩放到图层）和 View 菜单里的 Zoom to All Data（⌘0）都会飞到这个范围。
又称bounds · bounding box · bbox · 边界 · 外接矩形
分辨率（像元大小） Resolution (cell size) #

栅格里每个格子在地面上有多大。热浪和高程示例的格子都是 0.5°（赤道附近约 55 公里），所以每个值是一大块方格的平均，不是某一个点的值。

在应用里栅格图层的 Details（详情）标签页。
又称cell size · pixel size · 0.5 degree · grid spacing · 像元
缓冲区 Buffer #

离某个东西一定距离以内的区域，比如香港周边 100 公里以内，或每条台风路径两侧 50 公里以内。GIS 软件里叫 “缓冲区”，凌波微图里叫 “Show an area within a distance”（显示一定距离内的区域）。

在应用里卡片上的 Show an area within a distance of each 按钮，所有人都能免费使用。在凌波微图 Pro 里，还可以在提问框里直接问，例如 “显示香港周边 100 公里以内的范围”。
在教程中查看台风：哪些风暴最猛烈 →
又称within a distance · radius · circle around · 距离范围 · 周边
假设 Assumption #

打开文件时应用替你做的判断，比如哪几列是坐标、某一列是什么意思。凌波微图不会一上来就问一堆问题，而是先按最可能的理解处理，用一行字告诉你，需要时点一下就能改。

在应用里图层卡片里的 Assumptions（假设）部分，每条后面都有 Change（更改）。
又称guess · interpretation · detected · 推断 · 识别
离线工作 Work offline #

凌波微图在你自己的电脑上读取文件，你打开的任何数据都不会上传。只有底图、地名搜索和检查更新会用到网络，而且一个开关就能把它们全部关掉。

在应用里View 菜单 › Work Offline。开启后底图会换成离线轮廓图，并提示 “Working offline: online backgrounds are off”。
又称offline · no internet · network · privacy · 断网
连接（表连接） Join #

按双方共有的一列，把一张表格里的信息接到地图上的地方去。例如把一张按国家名称列出 GDP 的表格，接到国家地图上。凌波微图会自己找出这个共有列，并告诉你有多少个地方匹配上了。

在应用里在已打开地图图层的情况下，再打开一张表格（不带坐标的 CSV 或 Excel 文件）。表格会缩进显示在图层下方，例如 “joined · 172 of 177 matched”（已连接，177 个中匹配 172 个）。它的菜单里有 Show joined fields（显示连接的字段）和 Unjoin（取消连接）。连接需要一列在图层里各不相同的值（每个国家只出现一次）；像 “类型” 这种会重复的列不能当作连接键。
又称table join · attribute join · merge · match · 关联
筛选 Filter #

只显示满足某个条件的要素，比如 “强度为五级”。其余的只是暂时隐藏，并没有删除；屏幕上会一直显示当前显示了多少个。

在应用里卡片上的 Filter（筛选）按钮会给出一句待补全的话，例如 “Show storms where strength is any of Category 5”（只显示强度为五级的台风），补全后点 Apply。图层上随即出现 Filtered:（已筛选）字样和 Clear（清除）链接。
在教程中查看台风：哪些风暴最猛烈 →
又称query · select by attribute · where · show only · 过滤
时间步 Time step #

随时间变化的数据里的一个时刻：格网中的某一天、某一月或某一年。地图一次只显示一个时间步。所有时间步共用同一套颜色范围，所以颜色变了，就说明数值真的变了。

在应用里地图底部的时间滑块：Previous step (←)（上一步）、Play（播放）、Next step (→)（下一步），以及日期（如 “16 Jul 2023”）和第几步。键盘 ← → 也能逐步切换。
在教程中查看2023 年热浪：随时间变化 →
又称time slider · frame · date · animation · play
矢量数据 Vector data #

由形状组成的数据：点（一座火山）、线（一条台风路径）、面（一圈城墙、一个国家）。每个形状是一个要素，带着自己的属性信息。矢量数据怎么放大都清晰。

在应用里图层名称下面的小字会写明内容，例如 “4,999 lines”（4999 条线）或 “1,251 points”（1251 个点）。GeoJSON、GeoPackage、Shapefile、KML，以及带坐标的 CSV 文件，打开后都是矢量图层。
在教程中查看台风：哪些风暴最猛烈 →
又称vector · points lines areas · shapes · 矢量
属性 Attribute #

跟每个要素存在一起的一项信息，例如台风的名字、年份、最大风速。同一项属性的所有值合起来叫一个字段，也就是表格里的一列。

在应用里卡片上的属性列表、图层 Overview（概览）里的 Values 部分，以及 View data（查看数据）表格里的各列。Details › Fields 会列出每个字段，以及应用把它当作什么来理解（数值、类别、名称、日期等）。
在教程中查看台风：哪些风暴最猛烈 →
又称field · column · property · value · 字段
属性表 Attribute table #

图层的表格视图：一行是一个要素，一列是一项属性。在表格里选中一行，地图上对应的要素也会选中，反过来也一样。

在应用里卡片上的 View data，或图层右键菜单里的同名项。表格从地图底部拉出；点列标题可以排序。
在教程中查看台风：哪些风暴最猛烈 →
又称table · spreadsheet · view data · 表格 · 数据表
提问框（Pro） Ask box (Pro) #

凌波微图 Pro 里位于地图底部的输入框，你可以用大白话（打字或语音，中英文都行）询问关于图层的问题。助手只负责挑选应用里经过检验的分析步骤；所有数字都在你的电脑上计算，发送出去的只有图层的描述（名称、字段、范围），绝不包括数据值本身。

在应用里地图底部写着 “Ask about your layers” 的输入框，旁边有麦克风按钮可以语音输入。
在教程中查看台风：哪些风暴最猛烈 →
又称assistant · AI · natural language · question · chat
投影 Projection #

把圆圆的地球摊平成平面地图的方法。任何平面地图都会有变形：在常见的网络地图（Web 墨卡托投影）上，格陵兰看上去和非洲差不多大，其实非洲约是它的 14 倍。凌波微图和大多数地图应用一样用 Web 墨卡托投影来显示，但计算距离和面积时按真实的地球来算。

在应用里不需要你来选。图层的 Details（详情）标签页会显示文件自带的 Coordinate system（坐标系）；应用会自动换算以便显示，原文件不会被改动。
又称map projection · Web Mercator · Mercator · 墨卡托 · 地图投影
图层 Layer #

地图上的一组内容，比如所有城市、所有台风路径，或者一张气温格网。图层像一叠描图纸那样层层叠放，列表里排在最上面的那层就画在最上面。打开一个文件就多一个图层；移除图层不会删掉你的原文件。

在应用里左侧的 Layers（图层）面板，工具栏按钮 Layers（⌘L）可开关。每一行前面的眼睛图标用来显示或隐藏；拖动行可以调整上下顺序；右键可选 Style…、Zoom to layer、Rename、Remove from map。
在教程中查看台风：哪些风暴最猛烈 →
又称layers · shelf · overlay · 叠加
图例 Legend #

说明每种颜色或大小代表什么的那块小图。颜色表示数值时，图例显示数值范围；颜色表示类别时，图例逐一列出各个类别。

在应用里图层 Overview（概览）里的 Legend 部分；导出的地图图片里也有。
在教程中查看1866 年的中国城墙 →
又称key · colour key · color key · 说明
纬度和经度 Latitude and longitude #

地球上一个地点的 “门牌号”。纬度从南极的 −90° 到北极的 90°；经度从格林尼治向东、向西各 180°（−180° 到 180°）。上海大约在北纬 31.2°、东经 121.5°。

在应用里带经纬度列的 CSV（lat、lng、纬度等常见写法都认）会直接显示在地图上。导出图片时可以加 Lat/lon labels（经纬度标注）和 Grid lines（经纬网）。
又称lat · lon · lng · coordinates · degrees
无数据（NoData） No data #

一个格子或字段没有值，这和 “0” 不是一回事。在热浪示例里，没有热浪的日子和地方就是无数据，所以那里留空不上色，而不是画成 “0”。

在应用里点到这样的位置会显示 No value 或 No data。统计结果会说明排除了多少个。
在教程中查看2023 年热浪：随时间变化 →
又称NoData · missing value · fill value · null · blank
样式（符号化） Style (symbology) #

图层的外观：统一用一种颜色，或者让颜色跟着某个数值变化（越强的台风越红），或者按类别上色（每种城市类型一种颜色）。按数值给区域上色，制图学上叫分级设色图。

在应用里Style（样式）标签页：Color（颜色）、Palette（配色）、Size（大小）、Labels（标注）、Opacity（不透明度）、Outline（轮廓）。卡片上的 Color by a value（按数值上色）按钮是最快的入口。
在教程中查看1866 年的中国城墙 →
又称symbology · symbol · colour by · color by · choropleth
要素 Feature #

矢量图层里的一个 “东西”：一座城市、一场台风、一座有城墙的县城。在地图上它是一个形状，在表格里它是一行。

在应用里在地图上点击一个要素即可选中。右侧卡片会显示它的名称、各项属性，以及最多三行对比信息，例如 “highest of 4,999”（4999 个里最高）。
在教程中查看台风：哪些风暴最猛烈 →
又称object · record · row · shape · 对象
栅格 Raster #

以格网形式存储的数据，就像照片由像素组成，每个格子（像元）里存一个数值：海拔、气温、热浪强度等。放得足够大时，能看到一个个小方块。

在应用里点一下栅格，右侧卡片会显示这个格子的数值，以及它在整张格网里大概处于什么水平。在 Style（样式）标签页可以调 Palette（配色）和 Range（取值范围）。
在教程中查看2023 年热浪：随时间变化 →
又称grid · image · pixels · cells · GeoTIFF
坐标系（CRS） Coordinate system (CRS) #

把一对数字对应到地球上某个位置的规则。同样的数字放在不同坐标系下，指的是不同的地方，所以文件需要说明自己用的是哪一种。最常见的是 WGS 84，也就是 GPS 用的那一种。

在应用里Details › Coordinate system。如果应用只能推测，图层卡片的 Assumptions（假设）里会用一行字说明，旁边有 Change（更改）链接。
又称CRS · coordinate reference system · EPSG · datum · spatial reference
GCJ-02 与 BD-09（火星坐标、百度坐标） GCJ-02 and BD-09 #

中国大陆地图使用的坐标系。GCJ-02（俗称 “火星坐标”，高德、腾讯地图使用）相对 GPS 偏移几百米；BD-09（百度地图使用）在此基础上又多偏一点。从这些地图里复制出来的点，如果不转换，放到别的地图上就会偏出几条街。

在应用里当点位看起来像高德或百度坐标时，应用会问你一次：选 “Amap/Tencent coordinates (GCJ-02): convert”（按高德/腾讯坐标转换），还是 “GPS coordinates (WGS 84): keep where they are”（按 GPS 坐标保持原位），也可以先点 Compare on the map first（先在地图上对比）。
又称Mars coordinates · Amap · Gaode · Tencent · Baidu
GeoJSON、GeoPackage、Shapefile GeoJSON, GeoPackage, Shapefile #

常见的矢量数据文件。GeoJSON 是一个文本文件；GeoPackage（.gpkg）是一个数据库文件，可以装好几个图层；Shapefile 是一组同名文件（.shp、.dbf、.shx、.prj），要放在一起使用。

在应用里工具栏 Open（⌘O），或直接把文件拖进凌波微图（会提示 “Drop to add to the map”）。Details › Format 会写明格式。
又称.geojson · .gpkg · .shp · file formats · KML
GeoTIFF #

一种知道自己在地球上哪个位置的图像文件。高程模型和卫星影像常常是 GeoTIFF 格式。

在应用里示例 World basics（世界基础数据）里的高程图层就是 GeoTIFF。
又称.tif · .tiff · DEM · elevation · satellite image
NetCDF #

科学家常用来存气候和海洋数据的文件格式：随时间变化的格网，里面往往有好几个变量（气温、降水、风速等）。凌波微图能像打开普通栅格一样打开 .nc、.nc4、.cdf 文件，并配有时间滑块和变量选择。

在应用里示例 Heatwaves, summer 2023（2023 年夏季热浪）。在 Layers 面板里图层名下方，Variable shown 弹出菜单用来选变量；数据有深度或高度层时，还会出现 Level shown（显示的层）。
在教程中查看2023 年热浪：随时间变化 →
又称.nc · nc4 · climate data · ERA5 · CMIP6
WGS 84 #

GPS 背后的全球通用坐标系，用经纬度（单位为度）表示位置。表格里如果有经度、纬度两列，几乎都是 WGS 84。

在应用里卡片上会写 “Located using longitude and latitude as GPS coordinates (WGS 84)”（已按 GPS 坐标 WGS 84 用经纬度定位），后面有 Change（更改）。
又称GPS coordinates · EPSG:4326 · latitude longitude · GPS 坐标
